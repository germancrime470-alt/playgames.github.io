# Telegram Mini App — пример веб-приложения

Простое, но полнофункциональное мини-приложение для Telegram.  
Адаптируется под тему мессенджера (светлая/тёмная), показывает данные пользователя, отправляет события боту, поддерживает тактильную отдачу и главную кнопку Telegram.

## Возможности

- 🎨 Автоматическая подстройка под тему Telegram (цвета фона, текста, кнопок)
- 👤 Отображение имени и ID текущего пользователя (из `tg.initDataUnsafe`)
- 📤 Отправка пользовательских событий боту через `sendData()`
- 🔘 Главная кнопка Telegram (синяя) с обработчиком
- 📱 Вибрация (haptic feedback) при нажатиях
- ❌ Кнопка закрытия приложения
- 📦 Готовый HTML/CSS/JS без внешних зависимостей (кроме Telegram WebApp SDK)

## Демонстрация

Вы можете протестировать приложение, создав своего бота (см. инструкцию ниже).
